# Agent ArUco 真机适配层软件记录

日期：2026-10-24。分支：`codex/agent-visual-tools`。本记录证明真机适配层的软件行为，
**不证明本轮已经连接相机、串口、启用扭矩或完成真实机械臂验收**。

## 实现范围

- 复用 2026-10-18 已有真机证据的 ArUco ID 0 中央区域回中实现，不引入 LLM 电机控制量；
- 真机只暴露状态、检测、启动追踪、查询、停止追踪和全局停止六个工具；
- 后端只接受未修改的 `configs/visual_servo/aruco_center_mvp.toml`；
- 导入与构造不打开设备，检测只开相机，启动追踪才打开总线并启用扭矩；
- 动作开关、固定确认口令、显式串口/相机和交互式终端缺一不可；
- 停止先终止运动并保持扭矩，随后要求现场人员托住机械臂并输入本地确认才释放；
- 目标丢失、反馈/停止错误或释放失败不会自动重试或扩大预算。

真机专用 prompt 位于
[`hardware_visual.txt`](../../src/eai_robot/applications/agent/prompts/hardware_visual.txt)，
现场步骤和通过标准见[真机验收指南](../agent_hardware_acceptance.md)。

## 软件证据

假硬件端到端覆盖以下链路：

```text
模型选择状态 → 检测 → 启动 → 查询 → 停止
→ 本地人员确认 RELEASE TORQUE → 释放
```

相关 Agent 与视觉 profile 测试共 34 项通过。测试确认缺少授权时在实例化设备前拒绝，
真机后端构造不连接设备，工具结果不包含关节/电机目标，停止后要求释放确认。

完整离线回归 598 项通过；环境核验、仓库/文档链接检查、三个前端 JavaScript 语法检查、
`git diff --check` 和根包/SCS215 plugin 两个 wheel 构建通过。现场实物结果必须另记操作者、
设备、日期、代码提交、外部模型/API、停止方式及未完成项；软件测试不能代替该记录。

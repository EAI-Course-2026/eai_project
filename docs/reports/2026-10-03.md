## CI 纠正与修复

昨日 [PR #7](https://github.com/EAI-Course-2026/eai_project/pull/7) 最终 PR 检查成功，但同一任务的分支推送检查及 [main 合并后运行 37027581900](https://github.com/EAI-Course-2026/eai_project/actions/runs/37027581900) 中 Mac 离线测试失败。此前收尾结论未充分区分 PR 与合并后结果；不能据 PR 绿色宣称主线 CI 成功。

失败为 `test_lease_timeout_holds_and_late_renewal_cannot_restart`：托管机较慢，300 ms 输入租期可能在首次运动前过期，安全保持当前姿态，而测试仍要求已经运动。修复使用服务专属可控时钟，确认首次真实求解/模拟运动后推进租期；另加“工作线程启动前输入已经过期”回归，核验只保持、无运动且迟到输入不能重启。保留真实慢求解回归。生产租期、限位与求解保护均未更改。

CI 只对 main/develop 推送与目标为这两条分支的 PR 自动运行，避免功能分支 push 与 PR 重复。新增当前文档链接、仓库策略和前端语法检查。三个 required checks 来源锁定 GitHub Actions，合并后还需核对目标实际 SHA。

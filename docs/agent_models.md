# Agent 模型选择与百炼免费额度使用建议

核对日期：2026-10-24。面向当前课程开发、接口联调和小规模验收。
**团队默认先使用百炼北京的免费额度，不要求购买套餐或充值；额度不足或到期就停止真实调用，
继续离线回归，或在人工选择并验收其他有额度的模型后再测试。不自动转付费。**
这是项目使用策略，不表示百炼模型永久免费，也不是程序已实现账单限额的声明。

## 推荐组合

先复用已经跑通的基线，便于协作者复现和定位问题；模型建议基于本仓库已有证据，不是通用能力排名。

|---|---|---|---|
| 默认聊天与工具选择 | `qwen-plus`，Chat Completions，`extra_body={"enable_thinking":false}` | 已验证真实工具调用和回传；先稳定这条基线，普通控制意图无需默认长思考 | 100 万 Token |

| 当前语音回复 | `qwen-audio-3.1-tts-flash`，音色 `longanhuan_v3.1` | 已验证合成、播放与 ASR 往返；优先系统音色，不先做音色设计/复刻 | 100 万 Token |

不是本账号或每位协作者现在可用的余额。它们相互独立，不能加成一个任意模型通用的额度池。
API 兼容和免费资格也不等于任务质量合格；当前三模型真实证据见[报告](reports/2026-10-24-cloud-speech.md)。

以后接相机、持续识别或双工时再选匹配协议的视觉/实时模型；不能只改 model ID 就把现有按段管线当作 Omni。
不建议为演示先堆更大的模型、并行调用多家服务，或把控制器应承担的闭环交给模型反复推理。
多服务接口仍保留，项目默认测试路线先收敛到上述百炼组合。

## 免费额度前置检查

打开[百炼北京免费额度页面](https://bailian.console.aliyun.com/cn-beijing/costing-balance/free-quota)，
逐一核对实际调用的模型 Code、余量、到期时间、权限和「免费额度用完即停」状态。
使用北京通用 API Key，模型与接口区域一致；ASR 先在对应业务空间开通调用权限。
不要把 Coding Plan / Token Plan 的专属 Key 当作免费额度 Key。

免费资格限北京，通常有效 90 天，具体以控制台为准；同一主账号与其 RAM 子账号共享额度，
不同模型和快照分别计算。已认证账户未启用「用完即停」时，额度耗尽可能继续计费。
启用后耗尽会拒绝调用，常见原始错误为 HTTP 403 / `AllocationQuota.FreeTierOnly`。
规则与操作入口以[官方免费额度说明](https://help.aliyun.com/zh/model-studio/new-free-quota)为准。

**当前 Agent 不查询平台剩余额度，也没有在本地实现账单硬上限。页面「保存并使用」只校验配置，
不替你开启平台开关。真实测试前由账户操作者确认上述设置；未确认免费资格、余量或开关时先不调用。**
当前适配器会脱敏错误；平台额度限制可能显示成认证/服务错误，不保证界面出现原始错误码。
遇到限制先查控制台，不靠关掉开关、自动重试、换付费 Key 或临时购买套餐完成验收。

不要把免费额度当作所有云资源通用券；本项目建议使用当前已接入的实时推理 API，
不为省额度改走未经适配的 Batch、训练、模型部署或其他资源。本文不记录个人账户余额和 Key。

## 怎样把额度用于有效开发

1. **离线优先。** 日常跑 fixture、回归和 `agent --demo`；改 UI、schema 或文档无需请求真实模型。
2. **先文字后媒体。** 先离线运行 `agent --visual-demo`，再用真实聊天 API 通过
   「状态→检测 ArUco→启动追踪→查询→停止」工具用例；之后再开 ASR，最后开 TTS。
   不调音色时关闭「语音回复」，避免每个调试回答都合成一遍。
3. **控制回合长度。** `qwen-plus` 建议从 512–1024 输出 Token、非思考模式、简短自然语言回答开始。
   不是把预算降到能截断工具 JSON；若达到输出限额，先检查任务和响应，再显式调整。
4. **使用短而固定的语音样本。** 首次先一轮 TTS→ASR，接通后再三轮；功能验收重点包含否定和停止。
   每段建议 3–10 秒，按当前 30 秒音频和 1000 字符 TTS 上限设计任务。
5. **切换模型做可比实验。** 一次只改一个变量，固定任务、prompt 和工具；同时比较成功率、停止行为、
   延迟和 usage。没有通过工具回传/取消测试的模型，不替换当前基线。
6. **对照平台记录。** 每批测试前后刷新额度页，保留脱敏的模型、时间和 usage；控制台数据可能延迟，
   单次成功或返回 usage 不能证明本轮一定零费用。不要重复生成已经保存的固定测试音频。

可运行轮数取决于工具续轮、上下文和音频长度；不能拿文本 Token、音频 Token、字符或秒混算。
用当前任务集实测每个阶段的单轮用量，按最先耗尽的阶段安排测试预算，留出取消/失败重测余量。
UI 快照和 CLI 原始报告的统计能力不同，当前没有一个跨聊天/ASR/TTS 自动汇总的费用面板。

## 额度用完后的协作约定

停止这一服务的真实验收，记录失败和已完成的测试，继续离线开发。
如要改用另一个仍有免费额度的模型，操作者在页面显式选择，先完成兼容验收，再做新一轮任务测试；
不能自动切换模型掩盖失败，也不能把新模型的结果混入原基线报告。
确实需要付费时另作明确的预算与授权决定，不属于本指南默认流程。

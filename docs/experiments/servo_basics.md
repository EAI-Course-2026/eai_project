# 舵机基础实验说明

## 入口

先运行 `scripts/servo_setup.py --scan` 确认在线地址。改号时单独接一台，使用 `--old-id` 和 `--new-id`；写入后会独立查询编号和锁状态，不能仅凭收到了若干字节判断成功。

`read_position.py` 查询地址 56 的两个字节，并校验回复后按大端合成位置。`move_positions.py` 依次写目标位置；这两者分别演示读取反馈与发送目标。

## 双舵机比例映射

配置 `configs/hardware.local.toml` 的 `pair.first` 和 `pair.second`。对每个舵机：

```text
position = round(min_step + ratio × (max_step - min_step))
```

若 `direction=-1`，先把 ratio 转成 `1-ratio`。输入必须是有限的 0～1 数字。

保留的课堂例子：ID 2 的 0～512 输入 0.5 得 256；ID 3 的 0～256 输入 0.5 得 128。它们不是 90°/45°的精确校准，只是不同步数范围的演示。范围约束在程序侧，不会自动改变舵机 EEPROM 的硬件限位。

同次输入会依次发送给两台舵机，并校验应答。此版本没有使用 SYNC_WRITE，不能声称两台严格同时开始或同时到达。硬件未实测时也不能声称已满足整套课堂验收。

1. 实物型号、ID、接线与供电。
2. 指令格式：字头、ID、长度、指令、参数和校验和。
3. 每台 min/max 的选择依据，输入 0、0.5、1 的期望刻度与实测反馈。
4. 回复校验、错误输入和异常退出如何处理。
5. 真实验收结果、未通过项，以及代码/配置版本。

这是报告编写指引，不是已完成的实测报告。

# SO101 六关节本机上位机

在项目根目录启动：

```sh
uv run --no-sync python scripts/arm_desk.py
```

启动器只在 `127.0.0.1` 提供界面并自动打开浏览器，打开页面不会连接或移动舵机。若电脑没有自动打开浏览器，终端会显示可访问的本机 URL。默认使用 `configs/hardware.local.toml` 中的串口，也能在界面中改；可加 `--device-port SERIAL_PORT`，其中 `SERIAL_PORT` 要替换为本机设备名（Windows 如 `COM5`）。可加 `--no-open` 只打印地址。退出终端用 `Ctrl+C`；程序会尝试关闭扭矩和串口。

## 操作顺序

1. 支撑机械臂、确认空载且周围无遮挡。页面启动时列出系统检测到的串口，未连接时每 5 秒刷新，也可以点击刷新或手动输入。配置串口作为候选；只有一个可用串口且配置地址未检测到时，首次扫描会选择该设备。扫描只枚举设备，不打开串口、不验证舵机。
2. 选择原生串口或 LeRobot 后端，点“连接设备”。连接只读验证六台 ID、型号、硬件限位与状态。此时未接管，不会移动。
3. 点“开始控制（保持当前姿态）”。接管要求六关节当前位置在标定范围内、无状态报警且扭矩已关闭。程序将当前反馈写入目标并确认，再启用六台扭矩；不会先移动到固定起点。普通控制不依赖起点文件，即使缺失或与标定不匹配仍可接管。
4. 六滑杆使用原始标定范围对应的 0–1 数值。界面分别显示标定范围、可下发原始刻度范围、编辑目标、上次下发目标与实际反馈。普通运动目标使用标定区间内缩 20 刻度，与固定起点入口无关；修改过的关节才按新目标校验；未修改的关节用执行时实测反馈保持原位，端点余量区内的合法现有姿态不会阻塞其他关节。超范围新目标在写入前拒绝。拖动不会立即运动，点击“发送修改的关节”才执行。实际运动分段同步下发，并逐段更新反馈。
5. 每个关节有 ±5 刻度点动。点击立即执行，起点使用此刻实测反馈，其他关节保持实测姿态；不会执行滑杆中尚未发送的编辑值。被点动关节通常受内缩 20 刻度限制，最终到位容差为 2 刻度。若当前位置在标定范围内但处于端点余量区，仅允许朝内缩区间内部进行 5 刻度点动；禁止继续向端点移动。处在端点余量区内的其他关节可以保持原位，但不能借点动扩大目标范围。
6. 折叠区中的“移动到固定起点”独立执行固定起点路径，保留起点文件中的入口检查；预检拒绝不影响已启用的普通控制。演示同样需要匹配的起点和入口姿态，并最终返回起点。普通关节运动后，“已归位”状态会清除。
7. “释放扭矩 / 急停”可中断运动，并逐台关闭扭矩；停止后普通运动与点动均被锁定，需要重新从当前姿态接管。运动失败、部分扭矩异常、反馈故障或浏览器超过 8 秒无心跳也会尝试释放扭矩。页面关闭时额外尝试发停止请求。释放后需继续支撑机械臂；串口失联时切断电源是实体应急方式。

接管范围是标定范围；普通运动目标区间是标定范围内缩 20 刻度。两者都不使用固定起点的邻域限制。接管可以保持端点余量区内的现有姿态。发送仅执行已修改的关节，其他关节保持执行时的实测位置；界面不会把端点姿态自动裁剪并移动。固定起点与演示默认折叠，入口拒绝显示在该折叠区内，不作为普通控制的全局报错。

归位仍允许 3 刻度反馈漂移，指令保持在相应合法范围内。运动保持上次设备速度设置，不修改 EEPROM、PID 或舵机编号。每个子段最多推进 20 刻度，中间跟随容许 25 刻度，最终到位容差 15 刻度，单子段超时 8 秒。单关节范围与线性分段不能保证六关节组合不会碰撞；目前没有碰撞规划。

## 末端控制

切换左侧“末端控制”，与关节页共用串口及六轴接管。无需另开键盘终端；两种程序不可同时占用串口。页面显示 URDF 底座坐标系下 `gripper_frame_link` 的 XYZ，单位 mm。当前位置来自实际编码器正运动学，不来自命令积分；目标及跟随误差单独显示。关节映射、URDF、位置 IK 和直线规划共用课程模块。映射使用已加载标定端点和 drive_mode，不改硬件标定。模型位置依赖端点与 URDF 对齐，不能视为外部测量；第一版只约束 XYZ，末端朝向可能变化。

- 连续移动：默认 15 mm/s，可选 5/15/30，输入允许 2–30。按住 X/Y/Z 正负方向按钮移动，松开即暂停并写入实测位置保持；加速度限制为 60 mm/s²。开启键盘后 W/S=X±、A/D=Y±、R/F=Z±，组合方向按总速度归一化。
- 单步移动：点击方向按钮，执行选定的 1/5/10 mm 直线路径；完整预检失败则不执行半程。夹爪 ±5 刻度单独控制；XYZ 求解和执行保持其原始位置，包括合法的端点余量区姿态。
- 指定 XYZ：填入目标、预览完整路径，查看 XY/XZ 投影、距离、预计时间、五关节变化和模型朝向变化，再执行。单次直线最多 300 mm。预览 30 秒有效；执行前检查预览 ID 和六关节姿态变化，超过 2 刻度或被其他动作替代就要求重新预览。输入或速度变化会锁定执行，必须重新预览。无解路径可以显示已求解部分，但整条路径未通过时执行被锁定。
- 暂停运动 / Esc：取消剩余动作、读取新反馈并验证保持目标，保留扭矩与接管；恢复时从反馈重新建立轨迹。释放扭矩 / 空格：停止后逐轴关闭扭矩，需要支撑并重新接管。输入框获得焦点、页面切换、失焦、隐藏时清除方向输入，键盘需重新开启，不能自动续动。空格在输入框内不作为快捷急停；顶部释放按钮始终可用。

硬件始终由单一工作线程操作。方向输入只替换短时意图，不加入动作队列；独立连续会话及递增序号拒绝其他会话与乱序输入。客户端约每 80 ms 续期，后端按 20 Hz 目标周期执行；300 ms 无续期自动保持。普通页面状态轮询不能为方向意图续期；后台计时器暂停时也会过期。过期输入不能重新启动运动。实际周期受串口与求解耗时影响，不保证实物达到标称速度；超长读取或求解不会补发追赶运动。

每段使用上一解作为种子、限制关节变化最多 3°，新目标遵守现有标定内缩 20 刻度。端点余量区中的现有姿态可以保持，或逐步向内恢复。连续运动开始、单步和预览执行都使用新反馈；每个控制周期检查六关节位置、扭矩和状态，写入后核验目标寄存器。关节跟随差超过 12° 或 25 刻度、输入超时、路径受限或到位超时会暂停并保持，普通关节控制仍可用；扭矩丢失、反馈故障、目标未确认等硬件故障沿用释放扭矩流程。末端到位确认要求五关节差不超过 4 刻度且模型位置差不超过 3 mm；这是反馈确认容差，不是实物精度保证。XYZ 控制也不包含碰撞规划。

## 校准工作台

连接后可查看当前六关节硬件范围、方向与反馈。停止并支撑机械臂后，手动将各关节放在希望输入 0 和 1 对应的两个安全端点，分别点击采集；采集只读取位置。12 个端点齐全且每关节相距至少 20 刻度后，可以另存软件校准 JSON 与来源说明，不覆盖现有文件，也不写入舵机 EEPROM。

新校准不会自动取代当前运行中的文件。要使用它，用 `--calibration 新文件路径` 重新启动上位机。旧起点与新校准不匹配时，普通控制仍可独立接管，但归位与演示不可用；先支撑并关闭扭矩，手动摆好与新范围相容的姿态，点“只读采集当前姿态为新起点”。界面会立即启用新起点，后续启动可同时指定 `--calibration` 与显示的新 `--home-file`。起点示教会预检三个演示版本的所有目标，避免另存无法执行的起点。

# 单关节原始计数响应测试

本入口将视觉、FK/IK 与运动指令解耦。目前只测试底座旋转轴 ID 1；其他五轴
必须保持扭矩关闭，由操作者支撑并留出旋转净空。不修改 EEPROM、PID、死区或限位。

```sh
# 默认只读预检，检查完整正反向行程的余量
uv run --locked python scripts/joint_response.py
# 显式执行；操作前确认底座周围无障碍，Ctrl+C 取消并卸掉所选轴扭矩
uv run --locked python scripts/joint_response.py --execute
```

默认依次测试30、20、10、5、3、2计数，每个幅度正反方向各一次，每次返回起点。
仅所选轴接管当前位置并开启扭矩。相机不会打开，也不对其他轴下发保持目标。
若最大幅度没有观察到运动、反馈报警或回程偏离最初起点超过5计数，停止后续扫描。
每次运动以实际反馈为起点，不假定已精确回零；回程残差完整记录，不能算作到位。
所有目标仍限制在最初预检的正反向范围内，不因残差累积扩大测试行程。

每段采样1秒，目标计数一次写入、独立回读确认，随后约10 ms间隔读取反馈。
响应时间从目标发送前开始计时，报告首次同向位移、首次进入到位容差的时间，
以及是否发生在200 ms内。反馈时间为软件观测时间，包含通信延迟，不等于
电机内部控制周期；首个采样已晚于200 ms时结果不会被记作200 ms成功。

起动阈值取至少2个计数，并大于预检观测到的编码器抖动。到位容差最多1个计数，
始终小于测试步长；到位与实际运动分别报告，不因进入容差而提前结束采样。
结果只是当前姿态、负载、方向下的观测，不能当作全机械臂通用最小步长。
可靠阈值还需重复测试、从相同方向接近和不同负载验证，以区分噪声、回差及静摩擦。

原始采样 CSV、预检状态、每次目标/响应摘要和卸扭矩回读保存到忽略的
`local_artifacts/experiments/<timestamp>_base-joint-response/`。
实际物理转动须由操作者观察确认，编码器变化本身不能证明末端无回差或 FK 对齐。

2026-10-18 的 ID 1 实测：操作者确认大步有可见转动；5计数正反向均能起动，
约131–163 ms观察到至少2计数变化；4、3、2计数在当时姿态下未观察到编码器变化。
30计数起动约68–83 ms，但1秒后仍有2–3计数静态残差。
这是该轴、该姿态的实测结果，不能将5计数直接推广为所有关节的通用阈值。

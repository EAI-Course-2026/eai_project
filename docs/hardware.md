# 硬件登记

## 已知信息

- 已通过照片确认至少一台 Feetech SCS215 和微雪 Bus Servo Adapter (A)。
- 用户于 2026-09-22 确认已逐台完成编号；2026-09-27 明确当前 SO101 机械臂共 6 台 SCS215 舵机。
- 6 台的具体 ID 与物理标签对应、断电后复查情况尚未逐项登记；串口调试与实物检查记录见 [六关节控制说明](experiments/scs215_arm.md)。
- 已观察到的一台 SCS215：正 PWM 使位置刻度减小；其 PID 实验使用 `pwm_sign=-1`。不能未经测试把这个结论推广到每台设备。
- 已实测本机串口通信，1 Mbps；设备名保存在不提交的本机配置中；2026-09-27 六台型号、ID 和位置读取通过。
- 六台通信型号均确认 SCS215；实物关节对应与安全端点/方向仍需逐台核对。
- 用户确认使用另接充电宝的小电流模式供电；六台电压反馈约 4.9–5.0V。飞特官方入门资料建议 SCS215 使用 7–8.4V；当前已完成两版小幅同步演示；完整额定负载能力仍需核对，不能仅凭小电流模式判断供电合适。参见 [飞特官方教程，第 10 页](https://feetechrc.com/Data/feetechrc/upload/file/20201127/start%20%20tutorial201015.pdf)。

同一条总线的 ID 必须唯一。编号时每次只接一台，写入后检查新 ID，再断电重上电复查。扫描只能确认地址，不能证明不存在重号。

配置文件的 `pair` 保留旧实验：ID 2 为 0～512，ID 3 为 0～256。这是软件映射，并未写入硬件限位，也没有证明两个端点机械上可达。装上连杆后应重新测量并设置 `min_step`、`max_step`。`0` 表示校准后区间起点，不必对应绝对刻度 0。

2026-09-28 将 ID3 的 EEPROM 上限改为 771，并完成写后与重新打开串口的回读。2026-10-02 迁移时两种后端只读回读均为 771；迁移时腕部为 47..974，旧 4..1014 已归档。迁移阶段更新软件快照，没有改写舵机、移动机械臂或重新验证全行程。历史候选与实测见[原记录](experiments/scs215_safe_candidate.md)，当前规则见[共享基线](course/README.md)。

2026-10-02 手动范围标定已更新：用户确认六关节安全活动范围后，五个关节 EEPROM 限位已写入并回读，腕自转保留 47..974。自然停放反馈容差统一为 3 刻度，命令目标仍限于有效范围。详见 `docs/course/CALIBRATION.md`；笛卡尔零位及带动力轨迹尚未验收。

# 推理基建接续条件

本页只维护接手时需要补齐的条件；运行命令与能力表以[推理指南](README.md)为准。
应用级 ACT、SmolVLA、π0.5 适配、工件清单、传输、执行门禁和数据工具已经进入 develop；它们的存在不代表模型已适合本机任务。

## 开始下一项任务前

| 条件 | 需要的可检查输入 | 当前不能推断的结论 |
|---|---|---|
| 任务与评估 | 物体、布局、允许动作、成功判据、独立评估场景 | 能输出动作不代表能完成任务 |
| 相机与动作契约 | 实际相机键、时间戳、六轴顺序/单位/方向、标定摘要 | 合成三视角不代表现场有三台相机 |
| 数据与权重 | episode 来源、场景划分、固定 checkpoint/处理器 revision、统计 | 基础权重或 32 维截取不能当本机适配 |
| 算力与服务 | 已授权主机、系统、GPU/显存/驱动；真实 CUDA 诊断与时延 | Mac 的失败 CUDA 诊断不能当 GPU 验收 |
| 执行 | 先只读 shadow，再由操作者明确授权有限动作；保留停止与反馈门禁 | 人工键盘可动不构成自主 rollout 授权 |

软件契约检查无需等待全部设备到位。实物执行和外部付费调用分别授权，不从历史文档推断持续授权。不要扩大限位、放宽时限或伪造观测来跳过门禁。
